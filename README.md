# Corder 逐字稿小幫手

把中英文會議、線上會議、影片或任何電腦播放的聲音轉成逐字稿。使用 OpenAI Whisper（faster-whisper），**完全在本機執行**，音訊不會上傳到任何地方。

## 功能

- **轉錄檔案**：mp3、m4a、wav、flac、mp4、mkv、mov 等音訊或影片檔
- **即時錄音轉錄**：
  - 電腦音訊：Teams、Zoom、Google Meet、YouTube 等電腦播放的聲音
  - 麥克風
  - 電腦音訊 + 麥克風（線上會議時可以同時錄到自己和對方）
- 說話停頓時自動出字，錄音同時存成 WAV 檔（在 `recordings/` 資料夾）
- 錄完後可以「用錄音檔重新精準轉錄」，取得更完整的結果
- 支援中英夾雜，自動轉成繁體中文（台灣用語）
- 匯出 TXT 或 SRT 字幕檔

## 安裝

需要 Python 3.10 以上。

1. 雙擊 `安裝.bat`（第一次需要幾分鐘）
2. 雙擊 `啟動.bat` 開啟程式

第一次轉錄時會自動下載語音模型（large-v3-turbo 約 1.6 GB）。有 NVIDIA 顯卡時會用 GPU 加速，沒有就用 CPU（會比較慢，建議改選 `small` 模型）。

## 小提示

- 會議中英夾雜時，語言選「中文（含中英夾雜）」效果最好
- 錄電腦音訊時，錄到的是**預設播放裝置**的聲音；換耳機或喇叭後請重新開始錄音
